# KolAman 

מערכת לניטור התרעות, בדיקתם והפצתם לפי מחוזות
---

### הסבר קצר על המערכת:

המערכת מקבלת התרעות ממספר גורמים ביטחוניים שונים, מבצעת בדיקת כפילות, אימות והפצה של ההתרעות בחלוקה לפי איזורים.

בשלב זה העדפתי להישאר עם ארכיטקטורה גרועה אך עובדת. אעשה refactoring לאחמ"כ.
---

## How to run the system:
1. כנס לתיקיה הראשית והרץ ```docker compose up -d```
1. היכנס לתיקייה Gate והרץ:  ```dotnet run```
2. הכנס לתיקיית Classification והרץ: 
  - pip install confluent-kafka
  - pip install shapely
  - pip install geopandas
  - pip install pika
  - python

## רכיבי מערכת:

### רכיב - NotificationGate - קליטת התרעות

- כרגע המערכת יודעת להתמודד עם קבצים בסיומת json בלבד (אם אצטרך, אבדוק איך מוסיפים עוד סיומת)
- כרגע אני מריץ את הכל בmain ללא backgroundservice
- אני מטריג את המערכת כאשר נוצר קובץ בסיומת ready 

---

### רכיב Classification - בדיקת ההתרעות

##### שלב reddis
- בדיקת כפילות מתבצעת לפי id
- כרגע הגדרתי ttl של 5 דקות - נראה לי שהודעה שחוזרת על עצמה בתוך 5 דקות, סביר להניח שהיא כפילות.

##### שלב ולידציות
- עשיתי ולידציות בסיסיות (לפרט)

##### שלב rabbit
- כרגע שליחה בסיסית לתור לפי השם של המחוז שצריך לטפל בהתרעות
- אין עדיין לוגים מחוסר זמן

---
### רכיב CommandSystem
 - dotnet ef migrations add InitialCreate
 - מוסיף את כל ההתרעות לMysql אחד.
 - הייתי מעדיף לעשות את זה באלסטיק אם הייתי שולט. נראה לי יותר חכם לניתוחים ולחיפושים וכו'
 - עשיתי את הכל בטבלא אחת (כי בסופו של דבר השדות הם אותם שדות, ורציתי לחסוך זמן)
 - במקום לחלק לטבלאות הוספתי שדה region
 - לא עשיתי לוגים מחוסר זמן
 - כרגע אני משאיר את זה ללא חלוקה לקבצים, עם conectienstring hardcoded מחוסר זמן
